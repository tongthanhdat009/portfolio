# bootstrap

## Purpose
Application wiring for Laravel 13: route file registration, the Sanctum stateful API middleware that lets the first-party Next.js SPA authenticate with a session, and the JSON exception rendering that keeps every `api/*` response JSON.

## Key Files
| File | Description |
|------|-------------|
| `app.php` | `Application::configure()` — registers `routes/web.php`, `routes/api.php`, and `routes/console.php`, mounts the health endpoint at `/up`, appends `EnsureFrontendRequestsAreStateful` to the API middleware stack, and configures `shouldRenderJsonWhen` for `api/*` requests |
| `providers.php` | The provider manifest — a single entry, `App\Providers\AppServiceProvider` |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `cache/` | Generated `packages.php` and `services.php` — build output, never edited or documented |

## For AI Agents

### Working In This Directory
- Middleware and exception changes belong in the `withMiddleware` and `withExceptions` closures in `app.php`. There is no kernel class to edit.
- Keep the API JSON-only: `shouldRenderJsonWhen` matches `api/*` or `expectsJson()`. Anything added under `api/` inherits JSON rendering, including thrown `Symfony\Component\HttpKernel\Exception\*` errors.
- `EnsureFrontendRequestsAreStateful` must stay appended to the `api` middleware group — removing it breaks session-cookie auth for the Next.js admin at `localhost:3001`. The list of stateful domains comes from `SANCTUM_STATEFUL_DOMAINS` in `config/sanctum.php`, not from this file.
- The health route is `/up` (configured via the `health:` argument of `withRouting`). The compose service exposes it on port 9000.
- Never hand-edit `bootstrap/cache/*`. It is regenerated by `php artisan optimize:clear`, `php artisan package:discover`, or the Boost installer.
- New service providers go in `bootstrap/providers.php`.

### Testing Requirements
- From the repo root: `docker compose exec backend php artisan test`. From inside `backend/`: `composer test`.
- Bare-host `php artisan test` fails — the host lacks the MongoDB PHP extension.
- Middleware and JSON-rendering changes are observable through the API responses asserted in `tests/Feature/AuthTest.php` (unauthenticated admin calls must return JSON errors, not HTML redirects).

### Common Patterns
- `Application::configure(basePath: dirname(__DIR__))` returns a fluent builder; each concern is one `->with*()` call.
- Closure type hints on the callbacks (`function (Middleware $middleware): void`) keep the signature explicit.
- Config values are read through the `config()` helper at runtime; this file only wires classes and paths.

## Dependencies

### Internal
- `routes/api.php`, `routes/web.php`, `routes/console.php` — the route files registered here.
- `App\Providers\AppServiceProvider` — the provider listed in `providers.php`.

### External
- Laravel Sanctum — `Laravel\Sanctum\Http\Middleware\EnsureFrontendRequestsAreStateful`.
- `Illuminate\Foundation\Configuration\Middleware` and `Exceptions` — the fluent config objects.
