# work

## Purpose
The `/work` route — the archive of projects and case studies. Every project is rendered as an interactive card with its index and category, status, title, summary, tags, and links to the case study, live demo, and source repository. This directory holds the index; the case-study pages live in `[slug]/`.

## Key Files
| File | Description |
|------|-------------|
| `page.tsx` | Server component. Static `metadata` (`title: 'Work & Projects'`). Fetches `getProjects()` and renders a 1/2-column grid of `ui/Card`s. Each card shows an `{index} // {category}` chip, a status chip, the title linked to `/work/<slug>`, the summary, `ui/Badge` tags, a "Read Full Study" link, and conditional `demoUrl` / `repoUrl` external links |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `[slug]/` | `/work/[slug]` — case study detail page (see `[slug]/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- Server Component — no `'use client'`. Data comes from `getProjects()` only.
- `getProjects()` accepts an optional `{ category, featured }` filter; this page calls it unfiltered. The `relatedWorkLink` values in `src/content/capabilities.ts` point at `/work?category=…`, but this page does not read search params — that filtering is not wired up here.
- Each card uses `accent={project.accent}`, `border="md"`, `shadow="md"`, `interactive={true}`.
- External links (`demoUrl`, `repoUrl`) must keep `target="_blank" rel="noopener noreferrer"`.
- The header block (eyebrow `// ARCHIVE & CASE STUDIES`, oversized title `ALL PROJECTS`, intro paragraph) is hard-coded in the page, unlike the homepage hero which is CMS-driven.
- The card meta row shows `project.index` (a zero-padded string like `"01"`) and `project.category`.

### Testing Requirements
- `pnpm typecheck` from the repo root.
- `pnpm build` — the index is statically generated and `[slug]`'s `generateStaticParams` reads the same accessor.
- Manual: load `/work` in `next dev`, open a card, confirm the case study route resolves and the demo/repo links open.

### Common Patterns
- Same shell as `/lab` and `/notes`: breadcrumb → eyebrow + oversized uppercase title with `border-b-4` → card grid.
- The homepage `FeaturedWorkSection` shows one hero project plus at most four others; this index shows the full list.
- Project content comes from `src/content/projects.ts` (~1.6k lines, generated by `scripts/sync-github.mjs`) unless the CMS overrides it.
